# Dreame Wet & Dry Dashboard v1.0.0

The first stable release of the Dreame Wet & Dry Dashboard card for Home Assistant.

## Highlights
- Three tabs, **Operation**, **Device status** and **Maintenance**, built only on real Home Assistant entities from the Dreame Wet & Dry Vacuum integration.
- English and Hebrew UI, plus light and dark themes.
- Model-aware visual editor with H14 and H15 Pro Heat layouts.
- Official Dreame wordmark, with a text fallback if the logo cannot load.

## Since v0.1.0-alpha.3
No code changes. The same tested `dist/dreame-device-card.js` is now published as a stable release, so HACS tracks it without needing beta versions enabled.

## Validation
- `node --test tests/test_device_card.cjs`: 41 passed.
- Running daily on a live Dreame H15 Pro Heat (Home Assistant 2026.11).

## Notes
- The card does not install or replace the separate Dreame integration.
- H15 Pro Heat mappings that the integration marks as experimental stay experimental. Confirm write actions on the device.

Install through HACS as a custom **Dashboard** repository: https://github.com/matanmesika/dreame-device-card
