## Dreame Wet & Dry Dashboard v1.2.2

**New**
- The H15 Pro Heat photo now ships with the card and is shown by default. You no longer need to upload an image or set `image:` yourself.
- `image: none` shows the built-in drawing instead. A custom `image` still replaces the photo. H14 keeps the drawing.

**Fixed**
- If the bundled photo can't load (for example a manual install without the PNG), the card falls back to the drawing once instead of retrying on every update.

**Upgrading:** if your config has `image: /local/community/dreame-device-card/h15_pro_heat_app.png`, you can remove it. Manual installs: copy `h15_pro_heat_app.png` next to `dreame-device-card.js`.

No changes to device commands or entity mapping.
