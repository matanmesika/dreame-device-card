## Dreame Wet & Dry Dashboard v1.2.0

**New**
- `height` option: the card keeps one fixed size on every tab and the tab content scrolls inside it, so the dashboard layout no longer jumps when you switch tabs. Set it in the visual editor ("Fixed card height") or in YAML, e.g. `height: 720`. Leave it empty for the previous automatic height.

**Changed**
- Removed the "Mapping verified against the Dreamehome app" caption at the bottom of every tab.
- README rewritten: screenshots taken from the card with data from a real H15 Pro Heat installation, automatic vs. manual setup, and the full list of entities each part of the card uses.

No changes to device commands or entity mapping.
