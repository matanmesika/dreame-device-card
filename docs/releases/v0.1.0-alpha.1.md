# Dreame Device Card v0.1.0-alpha.1

First public **experimental** release of the standalone Home Assistant Lovelace dashboard card for Dreame H14/H15 wet & dry vacuums.

- HACS Dashboard custom repository packaging and downloadable `dreame-device-card.js` asset.
- Model-aware editor, device status, operation, and maintenance UI.
- Regression-tested device ownership and stale async operation safeguards.
- No changes to the underlying Dreame integration or device protocol.

**Not yet verified:** installation and mobile display on the user's Home Assistant setup; live operation/maintenance services with physical H14 and H15 hardware. This is not a stable release or an assertion of hardware compatibility. See `RELEASE_CHECKLIST.md`.
