## Dreame Wet & Dry Dashboard v1.1.0

The H15 card now follows the Dreamehome app: same tabs, same order, same names (English and Hebrew).

**Layout (like the app's main screen)**
- Self-Cleaning / Drying buttons and a **Cleaning Record** entry above the tabs.
- Tabs: **Mopping Mode** · **Washing and Drying Settings** · **Device Settings** · **Maintenance** (unchanged).
- Pages: Customize Settings, Set Wash & Dry Mode, Advanced Settings, Voice Assistant and Volume Settings, Cleaning Record.
- All labels and option names use the strings of the Dreamehome w2449e plugin, including the Hebrew translations.

**New**
- Cleaning Record: cleaning time today / 7 days, sessions, last cleaning, dirt-level split (needs integration sensors `h15_clean_time_*`, `h15_clean_sessions_week`, `h15_last_session`).
- Firmware Upgrade row (update entity `h15_firmware`).

**Fixes**
- Start Time is sent in seconds after midnight (the app's unit). Before, 08:00 was stored as 00:08.
- Voice volume uses the app levels 0 / 30 / 60, so the current level is shown instead of "Unknown".

Settings the app hides for the H15 (Cleaning Solution Ratio, timed drying after cleaning, per-mode return/scheduled duplicates) are no longer shown on the card.
