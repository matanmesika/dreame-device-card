# Dreame Device Card v0.1.0-alpha.3

Fixes the card getting stuck on **"Loading device…"** and refreshes the Dreame branding and documentation.

## Fixes
- The card no longer stays on "Loading device…" when Home Assistant pushes state updates while the card is still looking up the device. Device discovery is now tied to the HA connection instead of the `hass` object, which changes on every state update. Regression test added. (#10)

## Visual and documentation
- Compact official Dreame wordmark, with a text fallback if the logo cannot load. (#7)
- Transparent Dreame logo and a verified full UI gallery. (#8)
- README shows the logo first, plus all current dashboard screenshots. (#9)

## Validation
- `node --test tests/test_device_card.cjs`: 41 passed.
- Running on a live Dreame H15 Pro Heat (Home Assistant 2026.11).

**Experimental prerelease.** The card does not install or replace the separate Dreame integration.

Install through HACS as a custom **Dashboard** repository: https://github.com/matanmesika/dreame-device-card . Confirm that the version HACS shows is `v0.1.0-alpha.3`.
