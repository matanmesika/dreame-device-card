# Dreame Wet & Dry Dashboard v1.0.1

Maintenance release for the HACS page.

## Changes
- The official Dreame logo at the top of the HACS page is now served from this repository (`docs/brand/dreame-logo.svg`) instead of an external site.
- The logo sits on a light tile, so it stays readable in both light and dark Home Assistant / HACS themes.

## Card
No code changes. `dist/dreame-device-card.js` is the same tested card as v1.0.0.

## Notes
- The Dreame logo is used only to identify the supported devices. This card is not affiliated with Dreame.
