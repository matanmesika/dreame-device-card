# Dreame Device Card v0.1.0-alpha.2

Includes all code and documentation merged into main since the previous published release, including direct/manual HACS installation instructions, updated visual documentation, and automated regression checks.

**Experimental prerelease**. Device operation and H14/H15 mobile visuals have not been verified on physical hardware. The card does not install or replace the separate Dreame integration.

Install through HACS as a custom **Dashboard** repository: https://github.com/matanmesika/dreame-device-card . Confirm the version shown by HACS matches `v0.1.0-alpha.2`.
